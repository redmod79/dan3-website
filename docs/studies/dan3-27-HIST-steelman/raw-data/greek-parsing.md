## Mark 13:14 -- hestekota (masculine participle for neuter noun)

NOTE: The critical grammatical anomaly -- bdelygma is NEUTER but hestekota is MASCULINE. ## Revelation 13:16 -- charagma (mark)
```
Greek: ἵνα δῶσιν αὐτοῖς χάραγμα ἐπὶ τῆς χειρὸς αὐτῶν τῆς δεξιᾶς ἢ ἐπὶ τὸ μέτωπον αὐτῶν,

Key parsing:
- χάραγμα (charagma) G5480 = [N-ASN] "mark/stamp/brand" -- from charasso = engrave
- ἐπὶ τῆς χειρὸς (epi tes cheiros) = "upon the hand"
- τῆς δεξιᾶς (tes dexias) = "the right (hand)"
- ἢ (e) G2228 = [PRT] "OR"
- ἐπὶ τὸ μέτωπον (epi to metopon) = "upon the forehead"
```
NOTE: charagma = an engraved stamp/brand (used of images on coins, imperial seals). The OR between hand and forehead means the mark involves EITHER conscious allegiance (forehead) OR external compliance/action (hand). This contrasts with God's seal which is forehead ONLY -- requiring genuine conviction.
