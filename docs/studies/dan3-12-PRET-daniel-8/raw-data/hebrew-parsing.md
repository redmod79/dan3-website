```
וְעָמַד עַל־כַּנֹּו נִבְזֶה וְלֹא־נָתְנוּ עָלָיו הֹוד מַלְכוּת וּבָא בְשַׁלְוָה וְהֶחֱזִיק מַלְכוּת בַּחֲלַקְלַקֹּות׃

Key words:
- נִבְזֶה (nivzeh) = "despised/vile" — H959 bazah, Niphal.Ptcp.ms.Abs
- הֹוד מַלְכוּת (hod malkut) = "honour of the kingdom"
- בְשַׁלְוָה (be-shalvah) = "in ease/peacefully" — H7962 (same word as 8:25)
- בַּחֲלַקְלַקֹּות (ba-chalaqlaqot) = "by flatteries/intrigues" — smoothness
```

## Dan 11:23
```
וּמִן־הִתְחַבְּרוּת אֵלָיו יַעֲשֶׂה מִרְמָה וְעָלָה וְעָצַם בִּמְעַט־גֹּוי׃

Key words:
- מִרְמָה (mirmah) = "deceit" — H4820 (same as 8:25!)
- בִּמְעַט־גֹּוי (bi-me'at goy) = "with a small people" — H4592 me'at + H1471 goy
```

## Dan 11:27
```
וּשְׁנֵיהֶם הַמְּלָכִים לְבָבָם לְמֵרָע וְעַל־שֻׁלְחָן אֶחָד כָּזָב יְדַבֵּרוּ וְלֹא תִצְלָח כִּי־עֹוד קֵץ לַמֹּועֵד׃

Key words:
- כָּזָב (kazav) = "lie/falsehood" — H3577
- קֵץ לַמֹּועֵד (qets la-mo'ed) = "the end at the appointed time" — H7093 + H4150
```

## Dan 9:27
```
Key words:
- שִׁקּוּצִים מְשֹׁמֵם (shiqqutsim meshomem) = "abominations making desolate"
  NOTE: PLURAL shiqqutsim here vs. singular shiqquts in 11:31
  meshomem = Piel.Ptcp (same participial form as 11:31)
```

## Dan 12:11
```
Key words:
- הוּסַר (husar) = "was taken away" — H5493 sur, Hophal.Perf.3ms
  NOTE: Dan 12:11 uses Hophal of sur (passive of "remove"), matching 11:31's Hiphil of sur
  Dan 8:11 uses Hophal of rum (different root entirely)
- הַתָּמִיד (ha-tamid) = "the daily" — H8548
- שִׁקּוּץ שֹׁמֵם (shiqquts shomem) = "abomination of desolation"
  NOTE: shomem here is Qal.Ptcp (not Polel meshomem as in 9:27 and 11:31)
- יָמִים (yamim) = "days" — Daniel uses YAMIM here, not erev-boqer as in 8:14
```
