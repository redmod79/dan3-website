Key terms:
- יְבַלֵּ֑א (bela) = Verb.pael.Impf.3ms from בלה "wear out" — Pael stem = prolonged attrition

- זִמְנִ֣ין (zimnin) = Noun.mp.Abs from זמן "time"
- וְדָ֔ת (vedat) = Noun.fs.Abs from דת "law" — ABSOLUTE form (not construct)
- עִדָּ֥ן (iddan) = Noun.ms.Abs from עדן "time"
- וְעִדָּנִ֖ין (ve-iddanin) = Noun.mp.Abs from עדן "time" (plural)
- פְלַ֥ג (pelag) = Noun.ms.Cst from פלג "half"

  Both 10:2 and 10:3 use the yamim qualifier — doubly emphatic distinction from 9:24

## Daniel 7:20
```
Key Aramaic terms (from parsing):
- נפלו (nephalu) = Verb.Peal.Perf.3fp from נפל "fell" — three horns FELL before it
  Dan 7:8 uses etpe'al (passive/reflexive = "were uprooted"); 7:20 uses peal (active = "fell")
  Both describe same event from different perspectives: forcible uprooting (7:8) / resultant falling (7:20)
- חֶזְוַ֖הּ רַ֥ב מִן־חַבְרָתַֽהּ (chezwah rav min-chavratah) = "its appearance greater than its companions"
  rav min = comparative "greater than" — the horn LOOKED bigger than the other horns
  This is an APPEARANCE comparison within the horns, not the gadal chain
```
